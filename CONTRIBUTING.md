# Contribuer

- Une branche par tâche : `feat/…`, `fix/…`, `docs/…`, `chore/…`. Pas de commit direct sur `main`.
- Messages de commit : Conventional Commits en anglais (`feat(scope): résumé à l'impératif`).
- Toute Pull Request doit passer la CI et rester petite (une intention).
- Lance `pre-commit install` après le clonage.
- Les failles de sécurité ne se signalent pas dans une issue publique : voir SECURITY.md.
