# Security Policy

## Versions prises en charge
| Version | Prise en charge |
|---------|-----------------|
| 0.1.x   | oui             |

## Signaler une vulnérabilité
N'ouvrez pas d'issue publique. Écrivez à TODO@exemple.fr ou utilisez « Report a vulnerability »
(GitHub Security Advisories) avec : description, impact, étapes de reproduction, version concernée.
Accusé de réception sous 72 h ; point d'avancement sous 14 jours ; divulgation coordonnée.

## Périmètre
Dans le périmètre : le code et la configuration fournis. Hors périmètre : attaque physique prolongée,
déni de service volumétrique.

## Durée de support
Projet pédagogique : correctifs de sécurité assurés jusqu'au TODO.
